# الحركات التوضيحية 🎬 — خطوتي

بعض المهارات **تسلسل حركة** لا صورة واحدة: الوضوء، العجن، غسل اليدين، استخدام المقص، عبور الشارع…
لذلك لكل مجموعة من هذه المهارات «حركة توضيحية»: خطوات مرقّمة، وكل خطوة مشهد SVG متحرك بسيط + جملة تُقرأ وتُسمع.

> **لماذا حركة SVG لا فيديو؟** الفيديو ثقيل (عشرات الميجابايت)، ويحتاج شبكة جيدة، وغالباً يشغّل نفسه بلا إذن.
> الحركة المرسومة هنا **بحجم كيلوبايتات**، تعمل بلا إنترنت، ولا تتقدّم إلا بأمر الطفل، وتتوقف فوراً في الوضع الهادئ 🌿.

## ٢) كيف تظهر للطفل

في صفحة المهارة، مرحلة **👀 شاهد**، تظهر الحركة أولاً بعنوانها، ثم:

| الزر | ماذا يفعل |
| --- | --- |
| ▶ شغّل الحركة | يتقدّم خطوة كل مرة، ويتوقف في النهاية (لا يكرّر تلقائياً) |
| ⏸ إيقاف مؤقت | يتوقف في مكانه |
| ⏮ / ⏭ | الخطوة السابقة / التالية — للتنقّل اليدوي |
| 🔁 من البداية | يعود للخطوة الأولى |
| 🔊 اسمع الخطوة | ينطق جملة الخطوة الحالية |
| ☐ نطق تلقائي مع الخطوات | اختياري وغير مفعّل افتراضياً |

وفي أعلى صفحة المهارة شريحة **🎬 فيها حركة توضيحية**، وكذلك على بطاقة المهارة في القوائم.

### القواعد الملزمة داخل المشغّل

- **لا تشغيل تلقائي إطلاقاً** — الطفل أو مرافقه يبدأ بـ▶.
- **الوضع الهادئ 🌿** (أو «تقليل الحركة» في الجهاز) يوقف تقدّم الخطوات تلقائياً، ويُبقي التنقّل بالأزرار،
  وتظهر ملاحظة توضّح ذلك. كذلك تتوقف حركات المشاهد الداخلية (قطرات الماء، الفقاعات، العجين…).
- **كل خطوة لها جملة مكتوبة** تُعلَن لقارئ الشاشة عبر منطقة `aria-live` — فالحركة لا تعتمد على الصورة وحدها.
- **لا وميض ولا سرعة**: الانتقال بين الخطوات هادئ (٣٢٠ مللي ثانية)، وحركات المشاهد بطيئة (١.٦–٢.٦ ثانية).
- **الطباعة**: تتوقف الحركة، ويُطبع المشهد الحالي.

## ٣) البنية في المشروع

| الملف | الدور |
| --- | --- |
| `data/animations.ts` | تعريف الحركات: العنوان، الخطوات (جمل كل خطوة)، كلمات المطابقة، المهارات المسمّاة، ملاحظة السلامة |
| `components/animations/scenes.tsx` | مشهد SVG لكل حركة، يتغيّر بحسب رقم الخطوة (+ عناصر مشتركة: طفل، مغسلة، وعاء، تيار ماء، فقاعات) |
| `components/animations/StepAnimator.tsx` | المشغّل: الأزرار، نقاط التقدّم، النطق، احترام الوضع الهادئ |
| `app/globals.css` | حركات CSS للمشاهد (`kw-drop`, `kw-bubble`, `kw-squash`, `kw-sway`, `kw-slide`, `kw-wipe`, `kw-sparkle`, `kw-frame`) |

### كيف تُربط الحركة بمهارة؟

1. **بالاسم**: إن كانت المهارة مذكورة في `skillIds` داخل تعريف الحركة، فهي لها أولوية.
2. **بالمطابقة**: وإلا يُبحث عن كلمات المطابقة في (عنوان المهارة + النص الأصلي + الكلمات المفتاحية).

### إضافة حركة جديدة

1. أضف مفتاحاً جديداً في `AnimationKey` وتعريفاً في `ANIMATIONS` (خطوات + كلمات مطابقة + ملاحظة سلامة إن لزم).
2. ارسم مشهدها في `scenes.tsx` وأضفه إلى `SCENES`.
3. شغّل `npm run verify` — يتحقّق آلياً من: أن لكل حركة ٣ خطوات على الأقل، وأن كل جملة عربية غير فارغة،
   وأن لكل حركة مشهداً مرسوماً، وأن كل مهارة مذكورة موجودة فعلاً، وأن **كل حركة مرتبطة بمهارة واحدة على الأقل**،
   وأن حركة عبور الشارع تحمل تنبيه «محاكاة» (شرط سلامة).

## ٤) هل يمكن إضافة فيديو حقيقي لاحقاً؟

نعم، والموقع مهيّأ لذلك: أي مقطع تصوّره جمعية أو مركز تدريب (مثلاً: عجن الخبز في المطبخ الحقيقي) يمكن وضعه
في `public/video/` ثم ربطه بالمهارة. الشرط أن يبقى **بلا تشغيل تلقائي**، وأن تكون له بدائل نصية للصوت،
وأن يُطلب من المستخدم ضغط ▶. الحركات المرسومة تبقى الأساس لأنها الأخف والأسرع وتعمل بلا إنترنت.
