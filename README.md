# خطوتي 🌱

> **المستودع:** <https://github.com/aicoinvestai-a11y/ktwat> — الأصوات الملفات المرفقة داخل المستودع (٦٣ م.ب).

موقع ويب عربي تفاعلي لتنمية المهارات — **نتعلم مهارة جديدة... خطوة بخطوة**.

محتوى تعليمي وتدريبي للأطفال والأشخاص ذوي الإعاقة الذهنية واضطراب طيف التوحد، يُستخدم **بإشراف الأسرة أو الأخصائي**.
المحتوى مبني بالكامل على الاستمارة الملزمة: «استمارة التقييم والتدريب لمنتفعي المراكز النهارية الدامجة» (22 صفحة) — كل بند فيها له مهارة ونشاط في الموقع، **ولا يُحذف أي بند**.

> هذا الموقع ليس أداة تشخيص ولا علاجاً طبياً، ولا يجمع أي بيانات شخصية، ولا يحتوي أي تقييم أو درجات.

## التشغيل

```bash
npm install
npm run dev        # تطوير على http://localhost:3000
npm run build      # بناء الإنتاج
npm run start      # تشغيل الإنتاج

npm run coverage   # تقرير تغطية الاستمارة (يفشل إذا وُجد بند بلا مهارة)
npm run verify     # فحص المحتوى والملفات والتراخيص
npm run report     # تحديث docs/coverage-report.md
npm run review-sheet # تحديث docs/review-sheet.md (ورقة المراجعة البشرية)
npm run voice-manifest # تحديث قائمة الجمل الصوتية + ملفات التسجيل المسجّلة
npx tsx scripts/fetch-photos.ts        # جلب/تحديث الصور الحقيقية من Wikimedia Commons (بحث عام)
npx tsx scripts/fetch-photos-by-name.ts # إكمال الصور بأسماء ملفات محدّدة (تحقّق ترخيص آلي)
npx tsx scripts/photos-review.tsx      # ورقة مراجعة بصرية + جدول نسب (يحتاج sharp مؤقتاً)
npm run typecheck  # فحص الأنواع
```

## الصور الحقيقية والرسوم 🖼️

ترتيب العرض في \`VisualBox\` (يُطبَّق تلقائياً في كل الموقع بلا تعديل بيانات):

1. **صورة حقيقية** إن كانت موثّقة لهذا العنصر (\`data/photos.ts\` ← \`data/image-licenses.json\`) — الأوضح للأطفال في المرحلة الواقعية.
2. **رسم أصلي SVG** من مكتبة \`Pictograms\` إن لم توجد صورة.
3. **الرمز النصي** كعنصر نائب موثّق (الحالة المتبقية: صفر حالياً).

ملاحظة عرض: لوحة التواصل بالصور 🗣️ تستخدم **الرموز فقط** (\`mode="art"\`) لأنها وسيلة تواصل تحتاج شكلاً واحداً ثابتاً لا يتغيّر،
أما بقية الموقع فتعرض الصورة الحقيقية أولاً لأنها الأوضح للأطفال.

قواعد إضافة صورة (يفرضها \`npm run verify\`):
- الرخصة ضمن CC0 / ملكية عامة / CC BY / CC BY-SA فقط، مع نسبة المؤلف ورابط المصدر — وتظهر النسبة في \`/about\` وفي بطاقة النشاط المطبوعة.
- لا صور لأشخاص ولا محتوى غير مناسب (فحص آلي على العنوان والوصف والنسبة).
- كل صورة يجب أن يقابلها رمز مستخدم فعلاً في بيانات المهارات.

### مراجعة الصور بشرياً
`npx tsx scripts/photos-review.tsx` يولّد:
- `docs/photos-review.png` — ورقة بصرية مرقّمة لكل الصور.
- `docs/photos-credits.md` — جدول النسب والتراخيص بالأرقام نفسها، مع عمود «مناسب لطفل؟ ☐ نعم / ☐ تُستبدل».

وقسم (د) في `docs/review-sheet.md` يحوّل هذه المراجعة إلى قائمة فحص، ويفحص `npm run verify` أن عدد الصور في الورقة مطابق للبيانات.

## الصوت 🎧

> **ملاحظة إصلاح (2026-09-24):** كان في مرشّح تقليص الصمت خلل يقطع الجمل عند أول سكون داخلي،
> فتضرّر معظم التسجيلات. أُصلح المرشّح وأُضيف حارس في المعايرة وفحصٌ آلي يرفض أي ملف مقطوع،
> وأُعيد توليد الجمل بسكربت `npm run voice-restore`. التفاصيل: `docs/voice-incident.md`.

الصوت في خطوتي على ثلاث درجات، بالترتيب:

1. **تسجيل مسجّل مسبقاً** في `public/audio/voice/<المعرّف>.mp3` — يُشغَّل فوراً ويعمل بلا إنترنت (PWA).
2. **محرّك نطق الجهاز** (Web Speech) إن لم يوجد تسجيل.
3. **صمت آمن** بلا رسائل خطأ إن لم يتوفّر الاثنان — فلا تتعطّل التجربة أبداً.

- قائمة كل الجمل: `data/voice-manifest.json` (808 جملة: 20 ثابتة + 491 جملة أنشطة + 245 مهارة + 52 بطاقة لوحة، بعد دمج المكرّر).
- نص التسجيل الجاهز للشخص الذي يسجّل بصوته: `docs/voice-lines.md` (مواصفات فنية + جداول مرتّبة بالأولوية + مربّع تأشير لكل جملة).
- بعد إضافة أي ملف: `npm run voice-manifest` — فيُربط تلقائياً ويُحدَّث العدّاد في الإعدادات.
- **معايرة مستوى الصوت**: `npm run voice-normalize` يوحّد مستوى كل الجمل على مستوى كلام واحد
  (−15 وحدة LUFS للجَهارة المسموعة) بحدّ ذروة −1.5 dBTP، ويقلّص الصمت الزائد — فلا تبقى جملة «منخفضة»
  وسط جمل عالية، ولا حاجة لرفع مستوى الجهاز إلى أقصى حد. الفحص `8هـ` يمنع أي ملف أخفض من الحدّ.
  بعد أي توليد أو تسجيل جديد: `npm run voice-all` (توليد ← معايرة ← ربط).
- **إنتاج كل الملفات دفعةً واحدة**: `npm run voice-record -- --dry-run` يعرض المتبقي بلا أي اتصال،
  ثم بتعيين مفتاح مزوّد واحد (`ELEVENLABS_API_KEY`+`ELEVENLABS_VOICE_ID` أو `OPENAI_API_KEY` أو `TTS_ENDPOINT`)
  يولّد كل الجمل المتبقية بأسمائها الصحيحة تلقائياً — مع حارس يرفض أي نص قرآني، ولا يلمس أي تسجيل بشري موجود.
  وبعد أي إضافة: `npm run voice-manifest`.
- **القرآن لا يدخل قائمة الصوت إطلاقاً**: ملفات تلاوة حقيقية فقط، و`npm run verify` يفشل إذا ظهر أي نص قرآني في قائمة التسجيل.

## للاستخدام بعيداً عن الشاشة 🖨️

- **بطاقة نشاط لكل مهارة**: `/card/<skillId>` — صفحة طباعة نظيفة (A4) فيها: العنوان، الخطوات مرقّمة، الأدوات، تنبيه السلامة،
  مربعات «تدربنا ✓» للتأشير بالقلم، والتاريخ. والرابط ظاهر أيضاً في صفحة المهارة. لا تقييم ولا درجات في البطاقة.
- **ورقة المراجعة البشرية**: `docs/review-sheet.md` — تجمع كل ما ينتظر تحقّقاً بشرياً في مكان واحد:
  16 بنداً موسوماً `needsReview` (غموض OCR/طباعة) و24 بنداً دينياً، مع قوائم فحص للنص والسلامة وجدول سجلّ للمراجع.
  تُولَّد بـ`npm run review-sheet`، و`npm run verify` يفشل إذا أصبحت الورقة غير متزامنة مع البيانات.

## معيار القبول

المشروع مكتمل فقط إذا كان `missingSkills = 0`، أي أن **كل بند** في الاستمارة له صفحة ونشاط.
النتيجة الحالية: **245 بنداً = 245 مهارة، والمفقود 0** (التفاصيل في `docs/coverage-report.md`).

### إضافة بنود جديدة (بلا لمس المكوّنات)

1. أضف البند في `data/source/<domain>.ts` بالنص الأصلي والأرقام الصحيحة.
2. أضف سجلاً في `data/skills/<file>.ts` عبر `S({ sourceId, ... })` — يرمي خطأ إن كان المرجع غير موجود.
3. شغّل `npm run coverage && npm run verify && npm run report`.

## المبادئ الثابتة في التنفيذ

- **لا تقييم:** لا درجات ولا نسب نجاح ولا تشخيص. الإجابة الخطأ = «حاول مرة أخرى» ثم تلميح بصري هادئ (بلا ❌ ولا أحمر قوي ولا أصوات خطأ).
- **إشراف:** الأنشطة الواقعية والحساسة للسلامة (سكين، مقص، كهرباء، عبور شارع، مسامير، شاكوش، أثقال، قفز، درج، مواد تنظيف) موسومة 👨‍👩‍👧/⚠️ «بإشراف مباشر من شخص بالغ»، والخطير منها محاكاة فقط.
- **الصوت:** كل عنصر له 🔊 وإعادة بلا حد وبلا تشغيل تلقائي. القرآن بتلاوة حقيقية (بلا TTS إطلاقاً)، والنصوص التعليمية بنطق عربي قابل للاستبدال بتسجيلات بشرية.
- **السلامة النفسية:** الوضع الهادئ 🌿 دائماً، احترام `prefers-reduced-motion`، بلا وميض ولا Confetti ولا موسيقى عالية.
- **الخصوصية:** بلا حساب وبلا تتبّع وبلا كاميرا/ميكروفون/موقع. كل التفضيلات محلية على جهاز المستخدم، ويمكن حذفها كاملة.
- **إمكانية الوصول:** WCAG 2.2 AA — RTL كامل، دلالات HTML، تنقّل لوحة مفاتيح مع تركيز واضح، نصوص بديلة، أهداف لمس كبيرة، لا اعتماد على اللون وحده.
- **النص الأصلي:** `originalText` يُنسخ حرفياً ولا يُعدّل، والنص المبسط للطفل في حقول منفصلة، وأي غموض في المصدر يُوسم `needsReview` مع الإبقاء على البند.

## الموارد

- خطوط: Tajawal و Noto Kufi Arabic — محلية في `public/fonts`.
- أصوات البيئة: ملفات حقيقية من Wikimedia Commons بتراخيص حرّة — موثّقة في `data/audio-licenses.json`.
- التلاوات: **18 سورة** بتلاوة حقيقية عبر Al Quran Cloud، والنص العثماني من مصدر مراجَع — تحتاج مراجعة بشرية موثوقة قبل النشر الموسّع.
- الرسوم: مكتبة \`components/illustrations/Pictograms.tsx\` تضم **431 رسمة SVG مسطّحة أصلية** وتغطي **كل** رمز مستخدم في الموقع (427 رمزاً) — بلا أي عنصر نائب. تُربط بقيمة العنصر وتُعرض تلقائياً في كل الموقع عبر \`VisualBox\`.
- الصور الحقيقية: **30 صورة** من Wikimedia Commons بتراخيص حرّة (CC0/PD/CC BY/CC BY-SA) للأشياء التي يحتاج الطفل رؤيتها كما هي في الواقع، موثّقة في \`data/image-licenses.json\` ومعروضة في صفحة \`/about\`. لا توجد أي صورة لأشخاص.

## سياسة الرسوم (Pictograms)

لتحويل الموقع من «عنصر نائب» إلى رسوم أصلية موحّدة:

1. أضف رسمة SVG جديدة في `components/illustrations/Pictograms.tsx` بمفتاح هو **قيمة العنصر الحالية** (مثال: `'💧'`).
2. لا تحتاج تعديل أي ملف بيانات: `VisualBox` يستبدل تلقائياً كل ظهور لهذا العنصر في الموقع (الخيارات، البطاقات، المشاهد، لوحة التواصل).
3. شغّل `npm run report` لمشاهدة نسبة العناصر التي تستخدم رسوماً أصلية.

النسبة الحالية في تقرير التغطية: **العناصر النائبة = 0** (كانت 1721). كل عنصر بصري في الموقع يُعرض الآن برسم SVG أصلي موحّد الطراز،
ومعاينة المكتبة كاملة متاحة في `docs/pictograms-preview.html` (تُولَّد بـ`npx tsx scripts/preview-pictograms.tsx`).

## لوحة التواصل بالصور 🗣️

52 بطاقة في 7 مجموعات (أحتاج، أشعر، لا أريد/توقّف، أشخاص، أماكن، أفعل، آداب) مع نطق عند الضغط وطباعة كاملة.

> **تنبيه:** اللوحة تعليمية للتدريب على التعبير، وليست أداة «تواصل معزّز وبديل» (AAC) سريرية، ولا تُغني عن تقييم أخصائي النطق والتواصل. تُستخدم مع شخص بالغ، وبما يناسب طريقة تواصل الطفل.

## أدوات المراجعة والجودة

| الأمر | ماذا يفعل |
| --- | --- |
| `npm run verify` | فحص شامل قبل النشر: تغطية، صوت (جَهارة/قطع/وجود الملفات)، تراخيص، سلامة الألعاب |
| `npm run coverage` | تقرير التغطية لكل محور مقابل الاستمارة (يجب أن يكون missingSkills = 0) |
| `npm run review-pages` | يولّد صور صفحات الاستمارة (`docs/review-pages/`) لتُضمَّن في ورقة المراجعة |
| `npm run a11y` | تدقيق إمكانية الوصول آلياً: تباين الألوان المحسوب رياضياً، بنية العناوين، الصور والأزرار — لكل صفحات الموقع (يتطلب خادماً يعمل) → `docs/a11y-report.md` |
| `npm run review-sheet` | يولّد ورقة المراجعة البشرية: `docs/review-sheet.md` + نسخة قابلة للطباعة `docs/review-sheet.html` (فيها صور صفحات المصدر ونص السور آيةً آية) |
| `python3 scripts/check-arabic-ui.py` | يتأكد أن الواجهة عربية 100% (لا نص لاتيني ظاهر) — يحتاج الخادم شغّالاً |
| `npm run voice-restore` | يعيد توليد أي جملة ناقصة أو مقطوعة |
| `npm run voice-normalize` | معايرة الجَهارة المسموعة (−15 LUFS للكلام، ويمكن لأي مجلد) |

> ملاحظة: لا تُشغّل `voice-normalize` مرتين بلا حاجة (ترميز مزدوج)، والملفات الحالية هي المصدر.
